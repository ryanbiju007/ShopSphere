# 🛒 ShopSphere – Online Shopping Order Management System

**ShopSphere** is a desktop-based Online Shopping Order Management System developed using **Python and Tkinter**. It provides a simple and user-friendly interface to manage customer orders efficiently.

## 📌 Project Overview

The application helps manage shopping orders by allowing users to add, search, update, delete, and view order details in one place. It uses JSON file storage to save order information, ensuring that records remain available even after closing the application.

## ✨ Features

- **Add Orders:** Create new orders with customer and product details.
- **Search Orders:** Find existing orders using Order ID.
- **Update Orders:** Modify previously stored order details.
- **Delete Orders:** Remove orders with confirmation.
- **Display All Orders:** View all available orders in a Listbox.
- **Input Validation:** Ensures mandatory fields are filled and quantity is a positive integer.
- **Product Categories:** Choose from six different product categories.
- **Payment Options:** UPI, Card, and Cash on Delivery.
- **Auto-Save:** Automatically saves order records in a JSON file.
- **Live Statistics:** Displays total orders and total items ordered.

## ▶️ How to Run

1. Clone or download this repository.
2. Make sure Python 3 is installed.
3. Open the project folder.
4. Run the following command:

```bash
python Order_Management_APP.py
```

5. The ShopSphere application will launch.
